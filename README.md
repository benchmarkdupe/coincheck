# coincheck

Keyword landing pages for [CoinCheck](https://coincheck.clientelai.com), an
on-chain token risk checker.

Each page is a real document at a keyword-shaped URL, written only from claims
the product actually enforces. Where a capability does not exist
(cross-chain clustering, LP-unlock alerts) the page says so rather than
implying otherwise.

Built as a single repository on purpose. Do not mass-create repos: identical
descriptions with identical outbound links is a recognised spam pattern and
risks the account.
