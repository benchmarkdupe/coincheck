What the flow looks like

Create a CoinCheck account, paste the exported fomo key on the same page, then copy a permanent MCP link into Claude. No extension popup, no separate site.

Where the limits live

Per-trade SOL, per-wallet budget, the daily-loss breaker and the minimum-liquidity rule are enforced in the risk engine. The model cannot raise them because they are not in the prompt.

What it refuses to do

Buys under 1,500 dollars of exit depth, including zero. A trade you cannot exit is not a trade.

What it never does

It never blocks a sell. And an account with no wallet connected serves no tools at all, so a half-finished setup cannot trade.
