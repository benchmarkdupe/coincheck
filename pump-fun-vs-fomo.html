What is shared

Both launch on Solana, so the read is identical: authorities, concentration, pool coverage, holder clusters, deployer history. A checker does not need to know which platform a mint came from.

What differs

The launch mechanics and therefore the shape of the early holder set. A bonding-curve launch and a terminal launch distribute supply differently, so the cluster signal reads differently.

Connecting a wallet from either

CoinCheck links fomo and pump.fun keys through the same flow: account, paste the exported key, copy the MCP link. Both are supported; the choice of which platform label is only used for the help link.

What to do with the result

Treat a clean check as narrowing the field. The coordinated-exit risk is not readable on either platform and no tool reports otherwise honestly.
